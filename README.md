# 🍕 PizzaMya - Aplicación Web de Pizzería

Aplicación web completa para una pizzería con sistema de pedidos en línea.

## 🎨 Colores de la Marca

- **Naranja Principal:** `#FF5F06`
- **Rojo Principal:** `#DB1B26`

## 📱 Pantallas Implementadas

### Autenticación
- ✅ Login (`login.html`)
- ✅ Registro (`registro.html`)

### Navegación Principal
- ✅ Home / Inicio (`index.html`)
- ✅ Ordena (`ordena.html`)
- ✅ Mi Pedido (`mi-pedido.html`)

### Catálogo de Productos
- ✅ Pizzas (`pizzas.html`)
- ✅ Bebidas (`bebidas.html`)
- ✅ Combos (`combos.html`)

### Detalles de Productos
- ✅ Vista Detalle de Pizza (`detalle-pizza.html`)
  - Selector de tamaño (S, M, L, XL)
  - Selector de cantidad
  - Lista de ingredientes

### Carrito y Pedidos
- ✅ Carrito de Compras (`carrito.html`)
  - Gestión de productos
  - Resumen de pedido
  - Aplicar cupones
- ✅ Estado del Pedido (`pedido.html`)
  - Tracking en tiempo real
  - Estados: Recibido → Preparando → En Camino → Entregado

### Perfil de Usuario
- ✅ Mi Perfil (`perfil.html`)
  - Información personal
  - Estadísticas de pedidos
  - Opciones de cuenta
- ✅ Editar Perfil (`editar-perfil.html`)
  - Actualizar información
  - Cambiar contraseña
- ✅ Agregar Dirección (`agregar-direccion.html`)
  - Gestión de direcciones de entrega
  - Dirección principal

### Páginas Informativas
- ✅ Misión (`mision.html`)
- ✅ Visión (`vision.html`)
- ✅ Políticas de Privacidad (`politicas.html`)
- ✅ Términos y Condiciones (`terminos.html`)

## 🛠️ Tecnologías Utilizadas

- **HTML5** - Estructura
- **CSS3** - Estilos y diseño responsivo
- **JavaScript** - Funcionalidad e interactividad
- **LocalStorage** - Almacenamiento de datos del carrito y pedidos

## 🚀 Cómo Usar

1. Abre `index.html` en tu navegador
2. Navega por el catálogo de productos
3. Agrega productos al carrito
4. Procede al pago (simulado)
5. Visualiza el estado de tu pedido
